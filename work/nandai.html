NandAI, my two-assistant setup with house rules.

I use two AI assistants, Claude and Codex, as thinking partners for product work. NandAI is the shared memory and the rules that keep them useful.

Role
Designer and daily user
Built with
Claude, Codex
Status
Ongoing experiment

The problem

Every new AI chat started from zero, and it sounded sure even when it was guessing. I wanted assistants that remember my context and push back on me.

What it does

  • Shared memory. Both assistants read the same context, notes and handoffs.
  • Reusable workflows. PRD reviews, SQL checks and ticket drafts follow the same steps every time.
  • House rules. Show evidence, say when unsure, and wait for my OK before sending anything.

Who built what

I designed the workflow, the rules and the bar for good output. The assistants wrote most of the code. This site was made the same way.

What I learned

The context and rules around a model matter more than which model it is. I still make the calls.
